# Presets

Presets add archive-oriented defaults and tool detection. Use them when the
workflow shape matches the preset and you do not need to list every archive
entry manually.

Current presets:

- [none](none.md)
- [rails](rails.md)
- [ruby](ruby.md)
- [node](node.md)
- [node-turbo](node-turbo.md)
- [python-uv](python-uv.md)
- [go](go.md)
- [php-composer](php-composer.md)

Use `entries` or `cache-profiles` when a repo needs a more specific cache set.
